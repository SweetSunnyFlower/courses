# React 基础教程

## 引言

React 是一个用于构建用户界面的 JavaScript 库。

> React 让创建交互式 UI 变得轻而易举。

以下是其核心概念：

## 组件

组件是 React 的核心构建块。

> 组件让你可以将 UI 拆分为独立、可复用的部分。

## 状态管理

React 提供了多种状态管理方案：

### 状态管理对比

| 方案 | 适用场景 | 学习成本 |
| --- | --- | --- |
| Redux | 大型应用 | 较高 |
| Context | 中小型应用 | 低 |
| Zustand | 各种规模 | 很低 |

## 学习路线

1. 先学习 HTML 和 CSS 基础
2. 掌握 JavaScript ES6+ 语法
3. 学习 React 核心概念
4. 实践项目开发

## 总结

> 学习 React 需要循序渐进，从基础到进阶。
